# aylis-webview

Componente WebView do Aylis: a página fica numa vista nativa que a plataforma põe sobre o controle.

Este crate é uma peça do Aylis: os apps não dependem dele direto, e sim do
[`aylis`](https://crates.io/crates/aylis), que junta todos e liga só o que o projeto usa.
