# aylis-build

Usado no build.rs dos projetos do Aylis: embute forms, temas e assets no executável e o ícone no .exe.

Os projetos do Aylis usam este crate nas `build-dependencies`, chamado pelo `build.rs`; o
gerador de código da IDE já escreve as duas coisas, então não é preciso acrescentá-lo à mão.
